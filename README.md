# DumasWriterSшte

A midnight-blue, book-inspired promotional website and English getting-started guide for **DumasWriter**, a native Mac writing app.

Open `index.html` to view the site locally. `guide.html` explains how to set up a Library, write chapters, choose scenes, export a manuscript, and make backups. The site is static HTML, CSS, and JavaScript, with no package installation required.

To preview with a local server, run `npm run dev`. Run `npm run build` to package the public files into `dist/`. The build output is generated and is not committed.

The Mac App Store listing URL has not been provided. Set `appStoreURL` in `site-config.js` to the verified DumasWriter listing when available; until then the buttons open the App Store homepage and ask visitors to search for DumasWriter.

The website is for advertising and guidance. Writing happens in the installed Mac app, which keeps books as local Markdown files in the Library folder selected by the user.
